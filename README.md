# 🛍 ShoppingApp

## Overview
ShoppingApp is a modern e-commerce mobile application built with Kotlin and Jetpack Compose. It provides a seamless shopping experience, allowing users to browse products, add them to their cart, and make purchases effortlessly.

## 🚀 Features
- 🏬 Browse a variety of products
- 🛒 Add/remove products from the cart

## 🛠 Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Architecture:** MVVM
- **Networking:** Retrofit
- **State Management:** ViewModel + LiveData
